Agent Factory Flow

What happens to a spec between “start run” and “approve”. Each box is a Step Functions state in the af-pipeline state machine.

AI agent AWS service or check Fixer (retry) Human Run stops Success

What each part does

GuardrailBedrock Guardrails scan the spec before any agent sees it, and scan the generated docs before anything is packaged.AWS service
Architect, Coder, Tester, Reviewer, Docs, FixerEach is an AI agent (Strands) running on AgentCore Runtime. Each works in a Code Interpreter sandbox with no internet. Step Functions waits for the agent to report back.AI agent
Build: wheels, then testsTwo CodeBuild jobs run the tests independent of the agent. The first may use the internet to fetch wheels only; the second has no internet and installs from that wheelhouse.Gate, not AI
FixerOnly runs when something fails. It reads the failure log or the review findings, fixes the code, and the run goes back to the Tester.AI agent
ApprovalAn email carries the download link plus approve and reject links. The run waits up to 7 days. Approving does not deploy anything yet.Human
